# basic_python_game
#  6 Basic Games in Python

A collection of six simple interactive games developed using Python. These games are designed to practice basic Python programming concepts such as conditional statements, loops, functions, lists, user input, and random number generation while making programming fun and interactive.

## Games Included

### 1. Magic 8 Ball
An interactive fortune-telling game that answers user questions with randomly generated responses. It simulates the experience of a Magic 8 Ball using Python's random module.

### 2. Computer Memory Game
A memory-testing game where players need to remember and reproduce a displayed sequence. It helps demonstrate sequence handling, user interaction, and basic game logic.

### 3. Even or Odd Challenge
A number-based challenge where the player predicts whether a number is even or odd. The game uses random number generation and the modulo operator to verify the result.

### 4. Number Guessing Game
A fun game in which the computer generates a random number, and the player tries to guess it. The program provides hints to help the player find the correct number.

### 5. Rock, Paper, Scissors
A classic game where the player competes against the computer by choosing Rock, Paper, or Scissors. The program determines the winner based on the game's rules.

### 6. Tic-Tac-Toe
A two-player game played on a 3×3 grid where players take turns placing X and O. The game checks for winning combinations and detects draws.
